# 论文与学习资料管理

## 文件夹用途

```
论文/
├── UQ课程/         ← 每周课程 PPT、讲义、导师课材料
├── 辅导班/         ← 课外辅导机构发的资料
├── 文献笔记/       ← 读过的论文 → 结构化笔记（定义→例子→原理）
├── 我的论文/       ← 你自己写的论文草稿
└── README.md       ← 本文件
```

## 每次给我材料时，这么说就行

> "帮我整理这周的课程材料" — 然后发 PPT/PDF

我会自动：
1. 按课程名 + Week 建子文件夹
2. 提取每页核心内容，写成笔记
3. 标出"定义 / 例子 / 原理"三层

> "辅导班发了新资料" — 然后发文件

我会自动：
1. 按机构名 + 日期建子文件夹
2. 分类：讲义 / 习题 / 案例 / 其他
3. 跟 UQ 课程相关的，交叉标记出来

## 笔记格式（统一规范）

每份笔记按这个模板来：

```markdown
# [标题]

## 核心定义
- 这个概念到底是什么（用自己的话讲一遍）

## 例子
- 课堂上的例子
- 我自己想到的补充例子

## 原理 / 逻辑链
- 为什么会这样
- 跟其他概念的关系（画个简单的分支结构）

## 跟其他课程的关系
- 跟 [某门课] 的 [某个概念] 有关系
- （辅导班材料如有交叉也会标在这里）
```

## 格式要求

- 你发 PPTX / PDF / DOCX 我都能直接读
- 图片里的文字我要等后续 OCR 能力增强才能提取（目前只能读纯文本）
- 视频/音频材料：告诉我"这个是讲什么的"，我记录元信息，内容等以后处理
